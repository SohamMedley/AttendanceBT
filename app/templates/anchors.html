Why anchor at all?

A single-institution chain is only as trustworthy as the institution running it — an administrator with file access could re-mine the whole chain and every internal check would still pass. Anchoring removes that possibility: a single 32-byte Merkle root is published to a ledger the college does not control. No student data ever leaves the server — only that hash. If anyone later alters a record, the recomputed root stops matching the published one, forever.
