1. Verify a student's attendance

This looks the student's marks up in the chain and checks a Merkle proof for one of them. The proof uses only the hashes on the path to the root, so it shows the mark is inside the block without revealing the rest of the register.

2. Verify the whole chain

Recomputes every block hash, checks each block links to the previous one, and checks each Merkle root against its records.

3. Break it yourself

The register is a plain JSON file when you run this on a laptop. Open data/ledger.json, change a name or a status inside a block, save, then run the check above again. It will name the block that no longer matches. 

python manage.py tamper --block 1 --record 0 --field name --value "Someone Else"

python manage.py verify does the same check from a terminal.
