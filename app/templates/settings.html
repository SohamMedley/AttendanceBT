〉 Command reference
Everything the CLI can do, alongside the web app.

python manage.py demo --weeks 6    # six weeks of realistic history
python manage.py serve             # start this web application
python manage.py verify            # re-verify every block and transaction
python manage.py tamper --level 4  # demonstrate tamper detection
python manage.py anchor            # anchor pending records publicly
python manage.py student BCOE23AI001
python manage.py defaulters
python manage.py anomalies
python manage.py bench --max 5     # Proof-of-Work benchmark

python manage.py self-test         # verify the cryptographic primitives
python manage.py export --out data/chain_export.json
