{# ============================================================================ Inline SVG icons. Every icon in this app is drawn here as a stroked 24x24 path and inherits `currentColor`, so an icon is always the colour of the text around it and never a coloured emoji. That last part is the whole point. The first version of this interface used Unicode geometric characters as icons -- {{ icon('link') }} for the chain, {{ icon('anchor') }} for anchoring, {{ icon('settings') }} for settings -- which a browser is free to replace with a full-colour emoji glyph from the system font. On Windows they did exactly that, and the navigation turned into a row of mismatched, shiny stickers that ignored the page's colours and sizes. An SVG cannot do that.
