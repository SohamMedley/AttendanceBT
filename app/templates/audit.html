How the signature audit stays affordable

Verifying one ECDSA signature in pure Python costs about 25 ms, so a deep audit of a few thousand records takes tens of seconds the first time. Results are cached per block hash. Because a block hash commits to every transaction in the block, altering anything inside it changes the hash, misses the cache, and forces a re-verification — so the cache can never hide a modification. Subsequent audits complete in milliseconds.
